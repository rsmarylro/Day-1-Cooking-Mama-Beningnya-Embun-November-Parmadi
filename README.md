Nama : Beningnya Embun November Parmadi
Repository adalah tempat storage digital yang digunakan untuk menyimpan kode, file, image, dll.
Kegiatan workshop menyentuh topik mengenai prompt engineering dan memperkenalkan github kepada peserta.

Poin-poin yang dipelajari:
Prompt engineering
-Prompt adalah instruksi atau masukan yang diberikan kepada suatu model AI.
-Tambahkan konteks pada prompt agar AI lebih mengerti dan mengeksekusi

Keuntungan prompt engineering 
- Meningkatkan performa AI model
- Mengurangi bias
- Meningkatkan kontrol dan predictability

Git/hub
-Git adalah version control system yang melacak siapa, kapan, dan apa saja yang sudah dirubah dalam file
-Diciptakan oleh Linus Torvalds pada tahun 2005
-Cara kerja : Working directory - staging area - git directory

Git command
- Git init : memulai repo baru
- Git add : memindahkan file ke staging area
- Git commit -m ’message’ : menyimpan file ke repository
- Git remote add : add untracked file
- git push origin main 
- Git pull origin main
